# 📊 Traffic Tracker

Инструмент для отслеживания примерного трафика сайтов конкурентов.  
Веб-интерфейс + сохранение в Excel. Не требует установки Python.

---

## ⚡ Быстрый старт (Windows)

1. Перейдите на вкладку **[Releases](../../releases)**
2. Скачайте `TrafficTracker.exe`
3. Дважды кликните по файлу
4. Браузер откроется автоматически на `http://127.0.0.1:8080`

---

## 🔧 Сборка EXE через GitHub Actions

EXE собирается автоматически при каждом push в `main`.

### Запустить сборку вручную:
1. Перейдите на вкладку **Actions**
2. Выберите **Build Windows EXE**
3. Нажмите **Run workflow** → **Run workflow**
4. Подождите ~3 минуты
5. Скачайте EXE из раздела **Artifacts** или **Releases**

---

## 🖥️ Запуск из исходного кода (если есть Python)

```bash
pip install -r requirements.txt
python launcher.py
```

## 📁 Структура проекта

```
traffic_tracker/
├── launcher.py              ← Точка входа (Flask + автооткрытие браузера)
├── app.py                   ← Backend (парсинг трафика)
├── requirements.txt         ← Зависимости Python
├── templates/
│   └── index.html           ← Веб-интерфейс
├── static/                  ← Статические файлы
├── data/
│   ├── history.json         ← История проверок
│   └── traffic_report.xlsx  ← Excel-отчёт
└── .github/
    └── workflows/
        └── build.yml        ← GitHub Actions (сборка EXE)
```

---

## 📊 Что умеет программа

| Функция | Описание |
|---|---|
| 🔍 Анализ трафика | Оценка посещаемости по данным SimilarWeb и PR-CY |
| 📋 История | Сохранение всех проверок в JSON |
| 📥 Excel-отчёт | Экспорт данных в красиво оформленную таблицу |
| 🌐 Веб-интерфейс | Удобный интерфейс в браузере |
| 🚀 Без установки | Один EXE-файл, двойной клик |

---

## ⚠️ Важно

Данные по трафику являются **оценочными** (погрешность 20–40%).  
Для точных данных необходим платный API SimilarWeb или SEMrush.
